## Gotchas and how to run

- **Concern (medium)** apply_fifo is not first-in-first-out: candidates are sorted by remaining balance descending (sorted(ds, key=lambda d: -bal[d])), not by document date; the disabled v2 code ordered by due_dt. The 'FIFO' typ value is persisted to fin_cash.alloc_lines, so downstream readers will assume date ordering that does not exist.
